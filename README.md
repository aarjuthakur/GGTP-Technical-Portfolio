# Arju Thakur - Individual Projects

Project submissions for the GGTP India Sept 2026 Cohort (QA Engineering track) at Perficient.

## Overview

This repository contains all capstone projects completed across 4 weeks of the Global Graduate Training Program, progressing from Python fundamentals through manual testing to full-stack test automation.

## Projects at a Glance

| Week | Project | Type | Technology | Key Deliverables |
|------|---------|------|------------|------------------|
| Week 1 | [Capstone 0 - CityCare HMS](./Week%201/Capstone%200%20-%20Git%20and%20Python/) | Python CLI Application | Python 3.10+, unittest, Git | Hospital Management System with OOP, 12 unit test modules |
| Week 2 | [Capstone 2 - OrangeHRM Testing](./Week%202/capstone%202%20testing/) | Manual Functional Testing | Chrome, XAMPP (Apache + MySQL) | 43 test cases across 7 HR modules, 95% pass rate |
| Week 3 | [Capstone 3 - ShopEasy Manual Testing](./Week%203/capstone%203/) | Manual Black-Box Testing | Chrome, ShopEasy E-Commerce | 50 test cases, 14 business rules, 14 defects found |
| Week 3 | [Capstone 4 - E-Commerce Automation](./Week%203/Capstone%204/) | Automated E2E Testing | Playwright, TypeScript | 32 tests, cross-browser (Chromium/Firefox/WebKit), POM architecture |
| Week 4 | [Capstone 5 - MS Forms Automation](./Week%204/capstone%205/) | Automated Survey Testing | Playwright, TypeScript | 44 test cases, dual-target (local replica + live form), 15 input types |
| Week 4 | [Capstone 6 - ShopEasy Full-Stack](./Week%204/capstone%206/) | UI + API Automation | Java 17, Selenium, REST Assured, TestNG, Maven | 38 test methods (20 UI + 18 API), 14/14 defects found |
| Week 4 | [CP 4 - Enterprise E-Commerce](./Week%204/cp%204/) | Automated E2E Testing | Playwright, TypeScript, axe-core | Accessibility, visual regression, network mocking |
| Standalone | [MS Forms Automation Tool](./ms-forms-automation/) | Form Builder + Tester | Playwright, TypeScript, MCP SDK | CSV-to-MS-Forms creation and automated testing |
